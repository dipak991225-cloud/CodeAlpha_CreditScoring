# CodeAlpha - Credit Scoring System

## Project Overview
Ye project loan applicants ka credit score predict karta hai.
Machine Learning ka use karke bank ko help karta hai ki kisko loan dena safe hai.

## Features
- Applicant data se credit score prediction
- Good / Average / Poor category me classification
- Data cleaning aur feature engineering
- Model training aur evaluation

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

## How to Run
pip install pandas scikit-learn
python main.py
Paste karke bata, fir *Commit changes* dabayenge.
